🌿 EcoGreen Systems - Trabajo Práctico Obligatorio
Repositorio oficial con el desarrollo completo del proyecto integrador para la capacitación de programación de FormaTEC. La aplicación simula un sistema integral de gestión y monitoreo ambiental para una organización de desarrollo sustentable.

📂 Estructura y Módulos del Proyecto
El trabajo se divide en tres secciones independientes de desarrollo:

Ejercicio_1/: Procesamiento, limpieza y análisis estadístico de lecturas de sensores ambientales y métricas de ahorro energético.

Ejercicio_2/: Sistema de gestión de inventario basado en Programación Orientada a Objetos (OOP), uso de herencia (clases EquipoVerde y SistemaSolar), manejo de excepciones personalizadas (ErrorStockInsuficiente) y almacenamiento persistente en archivos JSON (ControladorInventario).

Ejercicio_3/: Validación y auditoría de un algoritmo de cálculo de huella de carbono mediante pruebas unitarias (unittest) y desarrollo de una aplicación web completa bajo el patrón MVT de Django (servicios de lógica, vistas, rutas, tests y panel administrativo con plantilla HTML en dashboard.html).

🛠️ Tecnologías y Herramientas
Python 3.x (Lenguaje base y lógica de negocio)

Django (Framework web bajo patrón MVT)

Unittest (Suite de pruebas y validaciones)

Bootstrap 5 & CSS (Diseño y estilos de la interfaz)
